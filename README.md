## What it does

`main.ts` (Node 22, stdlib only) writes exactly one original funny line to `/output/entry.txt`:

> My plants died of neglect, so I bought a cactus — it died of irony.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out-laughoff node main.ts
cat /tmp/out-laughoff/entry.txt
```
